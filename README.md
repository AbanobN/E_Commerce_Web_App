# E-Commerce Web (Spring Boot + Angular)

A **full-stack e-commerce solution** demonstrating end-to-end product management, authentication, and checkout workflows.

## 🧩 Features
- Product catalog, search & filters  
- Cart, checkout & order history  
- JWT authentication & roles (Admin/User)  
- Admin dashboard for CRUD operations  

## 🧰 Tech Stack
**Backend:** Spring Boot • JPA/Hibernate • MySQL  
**Frontend:** Angular • Angular Material

## ⚙️ Architecture
Monorepo: `/backend` + `/frontend`
- REST API under `/api`
- Angular client under `/client`

## 🧠 What I Learned
- Building REST APIs with Spring Boot  
- Secure login with JWT & guards  
- Full-stack deployment flow
